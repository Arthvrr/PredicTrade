Machine Learning Prediction (Linear Regression)
This model analyzes the historical prices of the selected period to find a linear correlation. It predicts the closing price of the next trading day and calculates the probable range using the historical Root Mean Squared Error (RMSE).

The model estimates the value of the next data point based on statistical correlation over the selected timeframe.
